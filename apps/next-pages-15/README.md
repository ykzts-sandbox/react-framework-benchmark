# Next.js 15 Pages Router

ルート、キャッシュ、Docker の形は [`apps/next-pages`](../next-pages/README.md) と同じ。バージョンは Next.js 15.5.27 と `next-rspack` 15.5.27。

webpack は `next build`。Turbopack は `next build --turbopack`。Rspack は `BUNDLER=rspack next build`。

計測タグは `benchmark-next-pages-15:webpack`、`benchmark-next-pages-15:turbopack`、`benchmark-next-pages-15:rspack`。
